# DiaPredict

Вебсистема підтримки прийняття рішень (СППР) для роботи з пацієнтами з ризиком цукрового діабету та діабетом 2 типу. Система оцінює ризик діабету, прогнозує рівень HbA1c і допомагає відстежувати ризик ускладнень на основі лабораторних даних.

> ⚠️ Проєкт має навчальний/дослідницький характер і не замінює консультацію лікаря.

## Можливості

Інтерфейс українською мовою, три вкладки:

1. **Скринінг** — для пацієнтів без діагностованого діабету: оцінка ризику розвитку захворювання.
2. **Ускладнення** — для пацієнтів із підтвердженим діабетом 2 типу: ризик ускладнень у відсотках, прогноз HbA1c, графіки та фактори способу життя.
3. **Лабораторні дані** — введення результатів аналізів із відображенням референтних норм.

## Запуск

1. Клонуйте репозиторій:

```bash
git clone https://github.com/ВАШ_НІК/НАЗВА_РЕПО.git
cd НАЗВА_РЕПО
```

2. (Рекомендовано) створіть віртуальне середовище:

```bash
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # Linux / macOS
```

3. Встановіть залежності:

```bash
pip install fastapi uvicorn scikit-learn joblib pandas numpy
```

4. Запустіть сервер:

```bash
uvicorn app:app --reload
```

5. Відкрийте у браузері: <http://127.0.0.1:8000>
